# Gap Finder — бот для поиска гэп-запросов YouTube

Пришли боту тему (например, `что если` или `what if`). Он:
1. Расширяет её через подсказки YouTube: тема + каждая буква алфавита. Это бесплатно и не тратит квоту.
2. Для лучших N подсказок берёт топ-10 выдачи через YouTube Data API: дату, просмотры и подписчиков канала.
3. Считает **гэп-скор 0–100** = √(спрос × слабость выдачи):
   - **спрос**: позиция в подсказках + видео, которые набрали в 3+ раза больше просмотров, чем подписчиков у канала;
   - **слабость выдачи**: старый топ (40%), мало видео точно по запросу (35%), малые каналы <10K подписчиков (25%).
4. Отвечает списком со ссылками на выдачу и присылает `gaps.csv` со всеми метриками.

## Ключ YouTube API
Google Cloud Console → новый проект → включить **YouTube Data API v3** → Credentials → API key.
Это бесплатно, биллинг не нужен. Квота — 10 000 единиц в день **на проект**, сбрасывается в полночь по тихоокеанскому времени (10:00 по Минску). Анализ одного запроса стоит 102 единицы, то есть около 98 новых запросов в день.
При `TOP_N=15` это примерно 6 запусков в день на ключ. Можно указать несколько ключей через запятую, бот переключается между ними сам.
Но **каждый ключ должен быть из отдельного проекта** — ключи одного проекта делят общую квоту. Повторные запросы в течение 24 часов берутся из кэша бесплатно.

## Запуск на VPS
```bash
git clone <repo> gapfinder && cd gapfinder
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
cp .env.example .env && nano .env      # BOT_TOKEN, YT_API_KEYS
python cli.py "что если" --top 5       # проверка без Telegram
python bot.py
```
Чтобы бот работал постоянно, запусти его через systemd или `screen`, как остальные боты.

## Фильтр мусора
Подсказки с играми, музыкой и тру-краймом (fortnite, free fire, killer, lyrics…) отсекаются **до** запросов к API — квота на них не тратится.
- свой список: `STOP_WORDS=tattoo,meme` в `.env`;
- разово в запросе: `zodiac myths -killer -tattoo`;
- если тема сама про игру (`minecraft what if`), её слово не фильтруется.

## Музыка и цитаты
Подсказки вроде `i never want to see your face again` — это строчки песен и трендовых звуков: топ там из клипов, поэтому выдача выглядит «слабой», но гэпа нет.
- если в топе ≥50% видео из категории «Музыка» (categoryId 10), запрос выкидывается до показа, бот пишет, сколько убрал;
- запросы, похожие на цитату (начинаются с I/you или смешивают «я» и «ты»), не удаляются, но их скор умножается на 0.6 и помечается «похоже на цитату или песню»;
- в стоп-слова добавлены маркеры эдитов и звуков (`sped up`, `slowed`, `edit`, `mv`…) и игры, которые забивают «would you survive…» (`fnaf`, `danganronpa`, `left 4 dead`, `katseye`).

Пороги — `MUSIC_DROP_SHARE` и `QUOTE_PENALTY` в `scoring.py`.

## Несколько тем за раз
Пришли темы в одном сообщении, каждую с новой строки (до 5) — бот обработает их по очереди.

## Тонкая настройка
Пороги и веса задаются в начале `scoring.py`. Стоит прогнать 2–3 знакомые ниши
и сверить результат со своим ощущением, а потом подправить веса.
